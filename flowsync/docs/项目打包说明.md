## 🚀 快速启动

### 1. 安装依赖

```bash
cd server
npm install
```

### 2. 配置环境变量

复制 `.env.example` 为 `.env`，填入你的智谱API Key：

```
PORT=3000
SERVE_STATIC=1
LLM_API_KEY=你的智谱APIKey
LLM_API_URL=https://open.bigmodel.cn/api/paas/v4/chat/completions
LLM_MODEL=glm-4-flash
```

### 3. 启动服务

```bash
npm start
```

### 4. 访问

打开浏览器访问：**http://localhost:3000/index.html**

## 🔧 常见问题

**Q: 没有智谱API Key能运行吗？**
A: 可以。系统有兜底回复机制，没有key也能正常使用，只是回复是预设的友好回复。

**Q: 支持移动端吗？**
A: 支持，页面是响应式的，手机浏览器打开也能用。

**Q: 数据存在哪里？**
A: 对话数据仅在本地内存中，不持久化。如果需要可以开启SQLite。

**Q: 可以接入其他模型吗？**
A: 可以。修改 `server/src/routes/chat.js` 中的API地址和key即可，兼容OpenAI格式的接口。
