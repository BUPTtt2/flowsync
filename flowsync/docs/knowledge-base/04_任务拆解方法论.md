# 任务拆解方法论

> 大任务像一座大山，一看就怕。
> 拆成小土堆，就不怕了。

---

## 为什么要拆任务？

### 1. 降低启动门槛
- 大任务 = 高心理门槛 = 拖延
- 小任务 = 低心理门槛 = 容易开始
- P型人启动难，所以拆解尤其重要

### 2. 减少 overwhelm（ overwhelm =  overwhelm
- 任务太大，大脑直接宕机
- 拆小了，大脑才敢想
- 想都不敢想，怎么开始？

### 3. 增加成就感
- 完成一个小任务 = 一个小胜利
- 小胜利积累起来就是大成就
- 正向反馈 = 更愿意继续

---

## 核心原则

### 原则1：第一步必须2分钟内能完成
- 是的，2分钟
- 不要"10分钟也不长啊"——不，就是2分钟
- 2分钟的目的是：**只要开始就等于完成了一半**
- P型人启动难，所以第一步一定要超简单

### 原则2：每一步都要具体到"做什么"
- ❌ "准备一下"
- ✅ "打开文档，写一个标题"
- 越具体越好，越容易执行

### 原则3：不用拆到完美
- 拆个大概就行
- 边做边调整也没关系
- P型人不喜欢被计划束缚
- 拆解是为了帮你开始，不是绑住你

### 原则4：允许做着做着就不做了
- 拆完了不代表必须做完
- 做一步是一步
- 不想做了随时可以停
- 没有"必须完成"的压力

---

## 拆解方法大全

### 方法1：时间倒推法（适合有deadline的任务）

从截止日期往回推：

例子：写一篇论文（还有两周）

1. 最后1天：修改润色
2. 倒数2-3天：写完整稿
3. 倒数4-7天：写各个章节
4. 倒数8-10天：收集资料
5. 第1天：确定题目和大纲
6. 第一步：打开文档，写个题目（2分钟）

**重点：从最后一步往前推，每一步都是"为下一步做准备"**

---

### 方法2：流程拆解法（适合线性任务）

按做事的顺序拆：

例子：做一个PPT

1. 确定主题 → 2分钟：在PPT首页写个标题
2. 列大纲 → 写5个章节标题
3. 找素材 → 找3张图片
4. 做内容页 → 先做第1页
5. 做美化 → 先调字体
6. 检查修改 → 通读一遍

**重点：按做事的先后顺序，一步接一步**

---

### 方法3：组成部分法（适合复杂任务）

把大任务拆成几个组成部分：

例子：搬家

1. 收拾衣服类 → 2分钟：找几个箱子
2. 收拾书类 → 先装一个箱子
3. 收拾杂物 → 收拾桌面
4. 收拾厨房 → 打包碗碟
5. 打扫卫生 → 扫地
6. 运输 → 联系搬家公司

**重点：按空间/类别拆，每个部分独立**

---

### 方法4：难度递进法（适合P型人）

从最简单的开始，逐步加难度：

例子：学一门新技能

1. 超级简单：看一个5分钟入门视频
2. 很简单：跟着做第一个小练习
3. 简单：做第二个练习
4. 中等：尝试做个小项目
5. 有点难：挑战进阶内容
6. 难：做完整项目

**重点：从最最最简单的开始，让大脑觉得"我可以"**

---

### 方法5：2分钟启动法（最适合P型人！）

不管什么任务，先找一个2分钟能做完的第一步：

| 大任务 | 2分钟第一步 |
|--------|------------|
| 写论文 | 打开文档，写标题 |
| 学英语 | 打开APP，背1个单词 |
| 健身 | 换上运动服 |
| 打扫房间 | 先收拾桌面 |
| 做饭 | 把米洗了泡上 |
| 看书 | 翻开书，读第一段 |
| 写代码 | 新建一个文件 |
| 做PPT | 新建幻灯片，写标题 |

**重点：只要开始了，后面的事就顺理成章了。**
**P型人最难的是开始，不是过程。**

## 不同类型任务的拆解示例

### 示例1：写文章/报告

**大任务：写一篇5000字的报告

拆解：
1. 打开文档，写标题（2分钟）
2. 列3-5个小标题
3. 写第一个小标题的内容（先写大概）
4. 写第二个小标题
5. 写第三个小标题
6. 开头结尾
7. 修改润色
8. 检查错别字

**重点：先搭框架，再填内容。不要一上来就想写完美的第一段。**

---

### 示例2：学习/复习

大任务：复习一整章内容

拆解：
1. 翻开书，看目录（2分钟）
2. 看第一节，划重点
3. 做第一节的习题
4. 看第二节
5. 做第二节的习题
6. 整理笔记
7. 做总复习题

**重点：一节一节来，不要想着"我要把整章都看完"。**

---

### 示例3：做家务/大扫除

大任务：打扫整个屋子

拆解：
1. 先收拾桌面（2分钟）
2. 扫地
3. 拖地
4. 收拾桌子
5. 擦窗户
6. 整理衣柜
7. 扔垃圾

**重点：从最容易的开始，做多少算多少。做不完也没关系，做了就比没做强。**

---

### 示例4：学新技能

大任务：学编程

拆解：
1. 打开教程，看第一段（2分钟）
2. 跟着写第一行代码
3. 写第一个小例子
4. 做第一个练习
5. 学第二个知识点
6. 做第二个练习
7. 尝试做个小项目

**重点：边学边练，不要想着"我要全部学完"。学到哪算哪。**

---

### 示例5：找工作/投简历

大任务：找工作

拆解：
1. 打开简历模板（2分钟）
2. 填基本信息
3. 写工作经历
4. 写项目经验
5. 改一改
6. 投第一个岗位
7. 投第二个岗位

**重点：简历不用完美，先有第一版再说。投简历也是，投一个是一个。**

## P型人专属拆解技巧

### 技巧1：拆到"觉得有点好笑的程度
- 还觉得难？继续拆
- 拆到"这也太简单了吧"的程度
- 简单到不好意思不做
- 这就对了

### 技巧2：不想拆了就不拆了
- 不用拆完全部
- 拆个前三步就行
- 后面的做着做着就知道了
- P型人边做边想很正常

### 技巧3：第一步一定要超简单
- 简单到不可能失败
- 简单到"做了跟没做一样"
- 但只要开始了，就不一样
- 启动效应就是这么神奇

### 技巧4：允许中途改变方向
- 拆完了觉得不对？改
- 做着做着想换个方式？换
- 拆解是工具，不是枷锁
- P型人灵活是优点

### 技巧5：做完一步就庆祝一下
- 每完成一步，给自己一个小奖励
- 喝口水、伸个懒腰、看一眼窗外
- 正向反馈很重要
- 大脑尝到甜头才愿意继续

## 常见误区

### 误区1：拆得越细越好
不是。
- 拆太细反而有压力
- 拆个大概就行
- 边做边调整
- P型人不喜欢太细的计划

### 误区2：拆了就必须按计划来
不是。
- 拆解是为了帮你开始
- 不是为了绑住你
- 做着做着想改就改
- 灵活是P型人的优势

### 误区3：必须全部做完才叫成功
不是。
- 做一步是一步
- 一步也比零步强
- 不要因为做不完就不开始
- 开始比完美重要

### 误区4：别人的拆解方法我也能用
不一定。
- 每个人习惯不一样
- 找到适合自己的方法
- 适合P型人的方法，可能跟J型人不一样
- 自己舒服最重要

---

## 一句话总结

**任务拆解的目的，不是让你做得更多更快。**
**是让你觉得："哦，这个好像可以试试。"**

只要能让你愿意开始，就是好的拆解。
做不完也没关系。
开始了，就赢了一半。✨
